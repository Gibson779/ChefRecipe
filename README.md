# 🍳 AI Recipe Generator

An AI-powered recipe generator built with **React** and **Vite** that creates delicious recipe recommendations based on four ingredients provided by the user.

Users simply enter four ingredients, and the app uses AI to generate a unique recipe complete with cooking instructions.

---

## 🚀 Features

- 🥕 Enter up to four ingredients
- 🤖 AI-generated recipe recommendations
- ⚡ Fast development with Vite
- ⚛️ Built using React functional components
- 🎯 State management with React Hooks (`useState`)
- 🖱️ Event listeners for handling form submissions and user input
- 🔄 Conditional rendering to display generated recipes
- 📱 Responsive and clean user interface

---

## 🛠️ Technologies Used

- React
- Vite
- JavaScript 
- CSS
- OpenRoute API
